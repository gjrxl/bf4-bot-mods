## 第一次安装

1. 完整解压，打开 **BF4 MOD助手.exe**。
2. 只有 BOT 包：选“只有 BOT 包”，安装到独立空文件夹，例如 `D:\BF4Mods`。已有 0.8.3：选“已有网页工具 0.8.3”，安装目录选原工具目录。
3. 选好游戏和原版 BOT 包目录，点 **安装／升级 MOD**，完成后打开踹哈助手。

游戏目录是有 `bf4.exe、Data、Update` 的文件夹；BOT 目录是有 `BF4Launcher.exe、Server` 的文件夹，不要只选 Server。

## V0.2 直接更新

**不用卸载，不用重新下载游戏或 BOT。**

1. 退出游戏和 BF4Launcher，停止原工具的服务和管理后台，再退出踹哈助手。
2. 新包解压到一个新文件夹，打开新版 **BF4 MOD助手.exe**。
3. **MOD 安装目录选之前装 MOD 的目录**，点 **安装／升级 MOD**，保留配置和存档。

不要直接覆盖游戏目录，也不要删除原安装目录或 `mod-backups`。详细步骤见包内 **安装教程.html**。

## 新增和改进

- 新版桌面助手：选地图、开服和调整功能集中操作。
- 主副武器通用，副武器范围可选；击杀回血、击杀回弹按需开启。
- 击杀回弹支持补充全部装备，回复量可选推荐档或自定数量。
- AI 使用喷子、狙击枪、半自动步枪的抽选权重可调。
- 修复换地图、下一局后全武器失效；记住玩家功能和动作／光影选项。
- 新程序图标，整理地图轮换、功能分组和状态提示。
- 保留此前开服失败、原工具无限备弹导致 AI 不开火、无散布不完整的修复。

## 使用前注意

- **只在本机单人 BOT 环境测试过，联机效果未确认。**
- **1秒死亡卡片：关闭击杀视角，重生时间倍率调到最低 1%。**
- **无散布会同时无后座，不喜欢就别开。**
- 使用时保留助手运行；改选项后点“应用辅助设置”，提示等待进服时，进服后会继续加载。
