## 三步安装

1. 完整解压，打开 **BF4 MOD助手.exe**。
2. 选择“只有BOT包”或“已有网页工具0.8.3”，选好目录，点击 **安装MOD**。
3. 勾选功能并保存，再开服、启动游戏。

只有BOT包：安装到独立的空英文目录，自带独立设置窗口。已有0.8.3工具：选择现有工具目录，可继续用原网页。安装前退出这份BF4和启动器，停止对应BOT服和管理网页。

**装过旧版MOD，先用旧包卸载/还原，再装V0.2，保留存档。** 卸载同样先退出游戏、停止BOT服，再在“卸载”页操作。

## 功能与本次修复

- 死亡卡片固定约1秒、允许在全体队友旁部署。
- 禁止全部AI使用镭射/灯光配件栏，开服时加载固定规则。
- 柔和画面、清晰画面、自动标记（实验功能）。
- 修复“无限备弹（需要换弹）”导致AI不开火。
- 修复玩家无散布的旧参数缓存和连射累积，AI散布不变，后座仍是独立开关。

本次弹药和无散布修复使用网页0.8.3原有的选项；独立设置窗口仍是原有功能。

## 使用前注意

- **仅测试过本机单人BOT，联机效果未验证。**
- 兼容的是**网页开服工具0.8.3**；只有原版BOT包也能安装。
- 使用1秒卡片前：关闭“击杀镜头”，将“玩家重生时间倍率”调到最低 **1%**，保存并重启BOT服。
- 约1秒指死亡卡片时长，重生仍受重生设置影响；**右键跳过尚未实现**。
- AI配件限制改动后需重启BOT服。需要完整战地四及 **BF4 LAN BOT ALPHA v0.1（2026-10-15）**；本包不含游戏本体或作者原版服务端。
