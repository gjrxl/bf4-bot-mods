## 安装与更新

完整解压 → 打开 **BF4 MOD助手.exe** → 选择目录安装。
首次安装选择独立空目录；已有0.8.6工具选择它的安装目录。
旧 MOD 更新前退出游戏、启动器并停止旧服务和后台，新安装器选择原 MOD 目录升级。不要直接覆盖游戏目录，不要删除存档和 mod-backups。
只有原版0.8.5工具、没有旧MOD时，请先用作者的0.8.6工具升级。详细步骤见包内「安装教程.html」。

## 使用前注意

- 仅本机单人 BOT 测试，联机未验证。
- 1秒死亡卡片需关闭击杀镜头、重生倍率设为最低1%；可用助手对应一键设置，保存后重启游戏服。
- 地图轮换、AI武器比例和灯光限制按界面提示保存并重启生效。
- 普通“无散布”会同时无后座，不喜欢别开。
- 画面、散布和特殊配备没有覆盖所有组合，遇到问题请附地图、枪名和报错截图。

安装前保留游戏资源和存档备份。历史测试曾出现资源目录丢失，原因未完全定位，离线检查通过不代表该问题已完全排除。
