# 踹哈 MOD V0.4

**适配 11.7 新版 · 特殊武器 · 画面优化 · 一键安装**

适配 **2026 年 11 月 7 日 BOT V2 全量包＋开服工具 0.8.5**。需要完整战地4本体；本包不包含游戏和原版 BOT。

## 本次重点
- 加入特殊武器、人机准度调节、监狱减雪与强光调整。
- 修复换图加载较慢时，全武器功能停止恢复的问题。
- 主页补上“保存轮换”和“重启游戏服”，整理辅助提示。
- 精简至约 76MB，保留踹哈助手和 MOD 功能，不附带原版独立界面个性化工具。

## 安装与注意
完整解压 → 打开 **BF4 MOD助手.exe** → 选择目录安装。只有 BOT 包也能安装。
首次安装选独立空文件夹；已装 MOD 升级选原 MOD 工具目录，不要直接覆盖游戏目录。安装前退出游戏和启动器，停止这份工具的服务与后台，保留资源和存档备份。
- 仅单人离线测试，联机未验证；最新换图恢复修复已通过离线回归，实际效果仍待进一步反馈。
- 1秒死亡卡片：在辅助页点“一键修改”（关闭击杀镜头、重生倍率最低1%），重启游戏服，从助手启动游戏。
- 地图轮换保存后重启游戏服；AI 武器比例和灯光限制也需要重启生效。
- 普通“无散布”会同时无后座，不喜欢就别开。
