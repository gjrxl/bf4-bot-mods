## 三步使用

1. 完整解压本包，双击 **BF4 MOD助手.exe**。
2. 选“只有 BOT 包”或“已有网页工具 0.8.3”，选择对应目录，点击 **安装 MOD**。
3. 在“设置”中勾选功能并保存，然后开服、启动游戏。

| 你现在的情况 | 安装时怎么选 |
| --- | --- |
| 只有原版 BOT 包 | 选“只有 BOT 包”；MOD 安装位置使用独立空英文目录。安装后有独立设置窗口。 |
| 已安装网页工具 0.8.3 | 选“已有网页工具 0.8.3”；MOD 安装目录选择现有工具目录。可以继续用原网页。 |

游戏、BOT 包均需先完整解压。已有工具用户安装前正常退出游戏、启动器，并停止该安装的 BOT 服和管理网页。独立窗口与原网页游玩时选一种；使用独立窗口时请保留它。

卸载：**退出游戏 → 停止 BOT 服 → “卸载”页点击“卸载 MOD”**。原工具、基础 BOT 文件、存档和备份保留。若装过旧版分享 MOD，先用旧版包还原，再装此版。

## 功能

- 死亡卡片固定缩短到约 1 秒。
- 允许在全体队友旁部署。
- 禁止全部 AI 使用镭射／灯光配件栏，开服时加载固定规则。
- 柔和画面、清晰画面。
- 自动标记（实验功能）。

更改设置前先退出游戏；AI 配件限制更改后还需要重启 BOT 服。**右键跳过尚未实现，本版使用固定约 1 秒死亡卡片。**

## 需要准备

Windows 10/11 x64、完整的战地四游戏，以及 **BF4 LAN BOT ALPHA v0.1（2026-10-15）** 原版 BOT 包。已有工具路线支持 **0.8.3**。本包不包含游戏本体或作者的原版 BOT 服务端。

安装、设置保存、失败回退和卸载已通过本机临时目录验证，15 项自动检查通过。新窗口的实际开服、游戏内表现和其他电脑兼容性仍待玩家测试。
